Art_Resource 文件夹结构
========================

请将美术资源按以下分类放入对应子文件夹：

Horses/
  蒙古马  - mongolian_run.png / mongolian_exhausted.png / mongolian_crazy.png
  伊犁马  - yili_run.png / yili_exhausted.png / yili_crazy.png
  纯血马  - thoroughbred_run.png / thoroughbred_exhausted.png / thoroughbred_crazy.png
  汗血宝马- ferghana_run.png / ferghana_exhausted.png / ferghana_crazy.png

  尺寸: 120x80 px (单帧), 多帧 Sprite Sheet 水平排列
  动画: run(奔跑) / exhausted(力竭) / crazy(狂暴)

Rider/
  骑手 - rider_ride.png / rider_jump.png / rider_fall.png

  尺寸: 60x100 px

Background/
  草地 - grass.png (2000x600 px)
  天空/远山 - sky.png (800x400 px, 可选)

Obstacles/
  岩石 - rock.png (60x60 px)
  栅栏 - fence.png (60x60 px)

UI/
  按钮、面板等 UI 元素（可选）
